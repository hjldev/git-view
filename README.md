# Git View

IDEA 风格的本地 Git 仓库可视化管理工具。后端用 Node.js 直接调用本机 `git` 命令，前端是 React 单页应用，在浏览器中使用。

## 运行

需要 Node.js 22.18+ 或 23.6+（后端直接以 TypeScript 运行）以及 Git 2.30+。

```bash
npm install
npm run build
npm link          # 安装全局命令 git-view（卸载：npm unlink -g git-view）
```

之后在任意 Git 仓库（或其子目录）中运行：

```bash
git-view          # 也可以写成 git view
```

- 不带参数时打开当前所在的仓库；不在仓库中则显示欢迎页（最近的仓库、浏览目录、克隆、初始化）。
- 也可以指定路径：`git-view ~/projects/my-repo`。
- Git View 已在运行时，再次执行只会在浏览器中打开对应仓库，不会报端口占用。
- 常用参数：`--port 7420`、`--no-open`。

不想安装全局命令时，也可以在项目目录中运行 `npm start -- <仓库目录>`。

开发模式（前端热更新，访问 http://localhost:5173）：

```bash
npm run dev
```

## 功能

**Git 日志**（对应 IDEA 的 Git 工具窗口 → Log）
- 提交图：分支/合并连线、分支与标签标记（`origin & main` 合并显示）、虚拟滚动，滚动到底自动加载更多
- 筛选：文本/哈希、分支、用户、日期、路径
- 左侧分支树：本地/远程/标签，按 `/` 分组；单击定位提交，双击只看该分支
- 右侧提交详情：变更文件树（含增删行数）、提交信息、父提交、包含该提交的分支
- 下方差异预览，双击文件在标签页中打开
- 提交右键菜单：复制修订号、优选（cherry-pick）、签出修订、与本地比较、比较两个提交、重置当前分支到此处（soft/mixed/hard/keep）、还原提交、撤销提交、编辑提交消息、新建分支/标签

**提交面板**（对应 IDEA 的 Commit 工具窗口，启用暂存区模式）
- 已暂存 / 更改 / 未跟踪 / 冲突 分组，按目录分组或平铺
- 文件级暂存、取消暂存、回滚、删除未跟踪文件、添加到 .gitignore、储藏选中文件
- 提交、修改上一次提交（amend）、提交并推送（⌘/Ctrl+Enter）

**差异查看**
- 并排 / 统一视图，IDEA 配色（修改蓝、新增绿、删除灰），词级高亮，语法高亮
- 折叠未更改片段，F7 / Shift+F7 跳转到下一处/上一处差异，忽略空白
- 代码块级操作：暂存、取消暂存、回滚单个代码块

**分支**
- 工具栏分支弹窗（类似 IDEA 的分支小部件）：检出、从分支新建、检出并变基、比较、显示与工作树的差异、变基、合并、推送、重命名、删除（可恢复）
- 本地更改会被覆盖时提供“智能检出”（自动储藏后恢复）
- 远程分支：检出为跟踪分支、使用合并/变基拉取、删除远程分支

**远程**
- 更新项目（拉取当前分支，自动储藏）、拉取（合并/变基/仅快进）、获取所有远程
- 推送对话框：预览待推送提交、设置上游、推送标签、`--force-with-lease`；被拒绝时可合并/变基后重推
- 管理远程仓库

**冲突解决**
- 冲突对话框：接受您的 / 接受他们的 / 合并…
- 三栏合并视图：逐个冲突选择您的、他们的或两者，也可手动编辑；继续 / 中止 / 跳过 合并、变基、优选、还原

**其他**
- 储藏：创建（含未跟踪文件、保留暂存区）、应用、弹出、删除、从储藏创建分支、查看储藏内容
- 注解（Blame）、文件历史、分支比较
- 文件监听自动刷新、深色/浅色/跟随系统主题

## 安全

服务只监听 `127.0.0.1`，并校验 Host / Origin 与 Content-Type，防止网页跨站调用或 DNS 重绑定；所有 git 命令通过参数数组执行，不经过 shell。

## 结构

```
server/        Node 后端：cli.ts 入口、index.ts HTTP 服务、api.ts 接口、parsers.ts 输出解析、watcher.ts 文件监听
shared/        前后端共享类型
src/           React 前端：views/ 各视图、dialogs/ 对话框、ui/ 通用组件
```
